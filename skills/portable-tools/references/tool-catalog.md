# Catálogo optativo de herramientas

Elige según el trabajo, disponibilidad, costo y preferencias de la persona. Ninguna fila es requisito de instalación del paquete.

| Capacidad | Ejemplos alternativos | Prueba operativa |
| --- | --- | --- |
| Código y versiones | Git local, GitHub, GitLab | Identidad del repositorio, rama, commit y lectura remota cuando aplique |
| Conocimiento y notas | Archivos Markdown, Notion, Obsidian, Google Docs | Página o archivo exacto releído |
| Archivos y respaldo | Disco, iCloud Drive, Google Drive, Dropbox, OneDrive | Bytes, acceso y relaciones del objeto de destino |
| Datos estructurados | SQLite, PostgreSQL, Neon, hojas de cálculo | Base, tabla, registro y consulta exactos |
| Correo y contactos | Gmail, Outlook, correo local, contactos del sistema | Cuenta remitente y destinatario exactos |
| Mensajería | WhatsApp, Slack, Teams u otro canal autorizado | Hilo, cuenta y estado de envío |
| Agenda | Apple Calendar, Google Calendar, Outlook Calendar | Calendario, zona horaria y evento exactos |
| Navegador e interfaces | API, CLI, CDP, navegador, Computer Use | Estado de la pantalla o respuesta nativa después de actuar |
| Móvil | iPhone, Android, emulador o conexión disponible | Dispositivo y app correctos, readback del cambio |
| Desarrollo y despliegue | Herramientas nativas, CI opcional, App Store, infraestructura elegida | Build, instalación, despliegue y aceptación separados |
| Automatización | Tareas manuales, cron, automations del producto, scripts | Frecuencia, costo, trigger y resultado observados |
| Integración entre servicios | Conectores nativos, Composio, MCP, scripts de API | Identidad y operación concreta, no sólo conexión |
| Diseño y contenido | Editores locales, generadores de imagen, audio, video | Archivo fuente, exportación y publicación separadas |
| Procesos empresariales | ERP, SAP u otro sistema autorizado | Entorno, objeto y operación exactos |
| Cómputo remoto | Servidor propio, nube o proveedor de GPU como Runpod | Host, costo, proceso y salida releídos |

El perfil en profile.json guarda sólo preferencias no secretas. Una celda vacía indica que aún no se eligió herramienta. Las skills pueden proponer alternativas en contexto y preguntar antes de configurar una elección durable.
