# Evidencia y procedencia

Identifica fuente, fecha, cuenta, objeto y estado de cada afirmación. Separa original, metadatos, copia, resumen e inferencia. Si se copia o migra un objeto, conserva el original hasta comprobar contenido y acceso en el destino, además de relaciones o consumidores que importen. Un hash idéntico ayuda a probar bytes, pero no prueba permisos ni contexto.

Para un cambio escribe una sola vez cuando sea posible y relee el objeto exacto. Si el resultado es incierto, lee antes de reintentar. Expón límites de cobertura y no conviertas un recibo en aceptación humana.

## Preferencias y alcance

Usa primero las preferencias no secretas elegidas al instalar en portable-tools/references/profile.json. Una preferencia vacía significa sin decidir. Sugiere opciones pertinentes y pregunta sólo cuando una elección cambie materialmente el resultado; nunca exige una marca, cuenta, nube o repositorio concreto. Una conexión configurada no prueba acceso ni ejecución. Antes de una escritura identifica cuenta, objeto y destino; después relee el resultado. No infieras permiso para pagos, publicaciones, borrados o ampliaciones de acceso.
